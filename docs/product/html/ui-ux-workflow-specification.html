Conventions WORKFLOW
p.005

Conventions used in this pack

Epistemic layers

Every detail view stacks Observation → Inference → Prediction → Recommendation → Decision. Inference never looks like confirmed fact.

Priority marks

P0 ship-critical for Stage 5 · P1 should ship · P2 later · LAB never in OPS builds.

Amber annotations

Callouts on compositions mark interaction or safety rules for reviewers.

Category language

Buttons say Record decision — never Engage / Fire / Jam / Launch.

OBSERVATIONMeasured / reported
→
INFERENCEModel / fusion
→
PREDICTIONForward envelope
→
RECOMMENDATIONPolicy suggestion
→
DECISIONHuman record
